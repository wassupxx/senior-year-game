## 2. Шрифты

```python
import pygame

FONT_PATH = "assets/fonts/RubikMonoOne-Regular.ttf"
FONT_BAD_SCRIPT = "assets/fonts/BadScript-Regular.ttf"

FONTS = {
    "txt1":      pygame.font.Font(FONT_PATH, 24),  # Панель 1, "Новая игра", описание конца игры и "Продолжить" или "Новая игра", название всплывающего события
    "txt2":      pygame.font.Font(FONT_PATH, 20),  # Панель 2, "действия:", панель 4
    "txt3":      pygame.font.Font(FONT_BAD_SCRIPT, 48),  # "Лог событий"
    "txt4":      pygame.font.Font(FONT_PATH, 36), # "Событие", "Победа", "Школьник выбыл"
    "txt5":      pygame.font.Font(FONT_PATH, 12),  # Варианты действий
    "txt6":      pygame.font.Font(FONT_PATH, 14),  # "Продолжить" в всплывающем событии и описание всплывающего события
    "txt7":      pygame.font.Font(FONT_PATH, 17),  # Эффекты от всплывающего события
}
```
