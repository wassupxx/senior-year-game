# Bug Reports

## BUG-001 — Стоимость действия прибавляется вместо списания

**Статус:** Open  
**Приоритет:** High

### Описание
При выполнении действия стоимость ресурса не списывается с игрока, а наоборот стоимость прибавляется к ресурсу.

### Шаги воспроизведения
1. Создать новую игру.
2. Создать действие со стоимостью `{"money": 2}`.
3. Выполнить действие через `do_action()`.
4. Проверить количество денег игрока.

### Ожидаемый результат
Если у игрока было 10 денег, после действия должно остаться 8.

### Фактический результат
После действия у игрока становится 12 денег.

### Дополнительно
Проблема обнаружена тестами:
- `test_do_action_without_target`
- `test_do_action_with_target`

## BUG-002 — Игра падает при выполнении действия без цели

**Статус:** Open  
**Приоритет:** High

### Описание
При выполнении действия, у которого нет эффекта на цель
(`target_effects = {}`), метод `do_action()` вызывает
`apply_effects()` у объекта `None`.

В результате возникает `AttributeError`, и выполнение игры
прерывается.

### Шаги воспроизведения
1. Создать `GameState`.
2. Создать действие без цели.
3. Вызвать `gs.do_action(action)` без `target_index`.

### Ожидаемый результат
Действие должно выполниться на текущем игроке:
- стоимость должна быть применена;
- `self_effects` должны быть применены;
- игра не должна завершаться с ошибкой.

### Фактический результат
Возникает ошибка:

`AttributeError: 'NoneType' object has no attribute 'apply_effects'`

### Обнаружено тестом:
`test_do_action_without_target`

## BUG-003 — Эффекты предыдущего события не очищаются после перехода хода

**Статус:** Open  
**Приоритет:** Medium

### Описание
После `next_turn()` текущее событие очищается, но `current_event_effects`
продолжает содержать эффекты предыдущего события.

### Шаги воспроизведения
1. Создать `GameState`.
2. Установить текущее событие.
3. Установить его эффекты в `current_event_effects`.
4. Выполнить `next_turn()`.
5. Проверить `current_event_effects`.

### Ожидаемый результат
После перехода хода:

```text
current_event = None
current_event_effects = None
```

### Фактический результат
```text
current_event становится None, но current_event_effects
сохраняет эффекты предыдущего события
```

### Обнаружено тестом:

`test_next_turn_clears_current_event`
