# Критерии приёмки

## US-1: Отображение ресурсов
- Панель с 5 ресурсами отображается всегда.
- Отображаются: стресс, деньги, друзья, домашка, буллинг.
- Значения обновляются после каждого хода.

## US-2: Выбор действий
- После выбора действий появляется панель с выбором цели (то есть, одного из 3 других игроков)
- Недоступные мне по ресурсам действия подсвечиваются серым
- Панель действий состоит из пяти вариантов и появляется после каждого события

## US-3: Событие
- Событие отображается на экране сообщением

## US-4: Логи событий
- Последние 5 сообщений видны на экране.
- Лог обновляется после каждого хода.

## US-5: Очки 
- Mentality_stability отображается у каждого игрока, как и ресурсы
- Обновляется после каждого хода

## US-6: Условие победы
- после того, как кто-то достигает 60 очков, на экране появляется сообщение с именем победителя и поздравлениями
- игра останавливается

## US-7: Проигрыш
- после того, как кто-то достигает 10 и более очков буллинга, на экране появляется сообщение с именем выбывшего игрока
- способность игрока применять действия после этого теряется

## US-8: Чей сейчас ход
- когда игрок ходит, его имя появляется на экране
